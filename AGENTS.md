# Project Instructions

## General

- Read the relevant documentation before modifying code.
- Do not modify unrelated files.
- Do not add new packages without approval.

## Laravel

- Use Form Requests for validation.
- Keep controllers thin.
- Put business logic in services when appropriate.
- Use Policies for authorization.
- Write tests for new business logic and features.

## Workflow

Before implementing a feature:

1. Read the relevant feature specification.
2. Inspect the existing implementation.
3. Propose an implementation plan.
4. Wait for approval before making major changes.
5. Run relevant tests after implementation.
